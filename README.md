# UFC Mod (Forge 1.20.1)
Замени папку `src` в Forge MDK 1.20.1 на эту и собери: `./gradlew build`. mod_id = ufcmod.

## Управление (Настройки -> Управление -> UFC Mod)
R стойка | ЛКМ джеб | ПКМ кросс | Z лоу-кик | X хай-кик | C защита (держать)
V уклонение / вырваться с земли | G тейкдаун | H болевой (держать) | P профиль бойца

## Профиль бойца
P - окно с ползунками: рост 150-215 см, вес 52-130 кг, размах рук (ape index) 94-108 %.
Команды: /ufc info, /ufc height <см>, /ufc weight <кг>, /ufc reach <%>
